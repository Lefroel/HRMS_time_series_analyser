This is a software that allows for processing of large datasets produced by the time-resolved high-resolution mass spectrometry.

In the out/ folder you can find the source code.

Focus.jar is an executable.
n4_Nar_Main.csv is an exemplary input file.

Requirements: Java JDK 22 or higher.

To process the test sample:
1. Open the jar file by double clicking.
2. Select the csv file as an input by clicking the blue file button and navigating the explorer popup.
3. Press the rightmost button with cogs to process the file (1st module). You can check the working status of the software by looking at the bottom dockbar.
4. After successful processing raw data you can filter the input for meaningful ion signals. To do that press the hopper icon. It should display a green tick by it meaning that the data is ready for filtration. Choose your desired parameter thresholds and press the OK button.
5. After processing you will be notified of the amount of ions that passed the filtration. After filtration the software will visualise any ion of this filtered list which can be chosen via the checklist on the bottom right of the window.
6. The output files for further investigation will be located in the same directory as the input file.
